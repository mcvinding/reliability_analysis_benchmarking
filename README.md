# reliability_analysis_benchmarking

This folder contains benchmarking tests and evaluation scripts for reliability analysis methods, focusing on neuroimaging data. The benchmarks are designed to assess various reliability metrics and compare implementations, primarily referencing functions from [reliability_analysis](https://github.com/mcvinding/reliability_analysis). Included are example datasets, analysis scripts, and results that highlight performance and accuracy across different approaches.

For further methodological details, see:
Vinding, M. C. (2025). A Unified Framework for Reliability Analysis in Neuroimaging With Krippendorff’s α. *International Journal of Imaging Systems and Technology*, 35(5), e70192. [https://doi.org/10.1002/ima.70192](https://doi.org/10.1002/ima.70192)
